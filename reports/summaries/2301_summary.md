### 📈 季月動能 — 單季V型爆發，營收與毛利率同步創高

這一頁在看「最近一季、最近一個月」有沒有動起來。光寶科 2026Q2 營收 527.0 億，QoQ +21.4% 大幅爆發，從 Q1 的 434.1 億一口氣收復，淨利更從 37.8 億跳升至 71.2 億、EPS 1.66→3.14 元近乎翻倍，毛利率 21.66% → 27.22% 飆升 5.6 個百分點，短期動能極強。若與去年同期 404.1 億相比，YoY 約 +30.4%，徹底擺脫前三季的橫盤整理。月營收連四個月溫升：5月166.9億→6月173.5億→7月186.6億→8月190.1億，8月 MoM +1.9% 續強，顯示電源與光電產品出貨與 AI 伺服器電源需求同步暢旺。整體是「量價齊揚、獲利爆發」的強動能格局，毛利率續航力是下一季關鍵。

### 📊 經營 — 營收V型反轉，毛利與費用結構均見改善

這一頁在看「本業賺不賺錢」。三年營收 1483 → 1371 → 1661 億，2024年探底後 2025年 YoY +21.1% 強勁反彈，CAGR +5.8%，V型反轉確立。毛利率 22.0% → 21.6% → 22.9%，2025年回升 +1.3 個百分點，終結下滑；營業費用率 12.2% → 12.2% → 12.8%（推銷4.59%+管理2.99%+研發5.25%）微幅墊高但可控，研發 87.2 億佔營收 5.25%，維持電源與光電技術投入。營業利益率 9.8% → 9.4% → 10.1%，2025年重回雙位數，較前一年提升 0.7 個百分點，說明營收反彈已帶動規模效益，本業賺錢能力穩健改善。

### 💰 獲利 — 獲利創三年新高，股東報酬重回高檔

這一頁在看「最後落袋多少」。稅後淨利 145.7 → 119.4 → 151.2 億，2025年 YoY +26.5% 創三年新高，淨利率 9.8% → 8.7% → 9.1% 同步回升；EPS 6.36 → 5.21 → 6.65 元，年增 27.6% 亦創三年新高。ROE 17.1% → 13.1% → 16.8%，重回 16% 以上優質水準，ROA 7.7% → 5.8% → 7.3% 同步躍升，賺錢效率回到高檔。現金股利 4.51 → 4.51 → 5.0 元，2025年配息率約 75%、殖利率 3.73%（除息價 134 元），配息率與殖利率均屬高配息族群，獲利完全回饋股東，含金量紮實。

### 🏦 財務 — 負債適中但流動比偏緊，存貨激增是唯一警訊

這一頁在看「公司欠多少、現金夠不夠」。資產 2056.9 億中，流動資產 1640.2 億、非流動 416.7 億；負債 1157.1 億、股東權益 899.8 億，負債比率 56.3% 屬適中偏高（60-70% 下緣）、但已連兩年微升（55.0% → 55.6% → 56.3%），流動比率 149.7% 連續下滑且首度跌破 150% 健康線，短期償債能力轉為需關注。存貨 342.6 億，YoY +27.8% 激增且遠超過營收增幅 21.1%，週轉壓力升，是三頁中最大風險點。現金部位 809.7 億較前一年 1006.8 億減少 19.6%，因配息與營運資金吃緊。現金流「營業 +145.3 億、投資 -73.9 億、融資 -231.0 億」——白話是「本業賺 145 億，投資 73 億，同時大舉配息還債 231 億」，營業現金流為淨利的 0.96 倍、獲利含金量良好；自由現金流 76.8 億扣除資本支出 68.5 億後仍正數，但較前一年 88 億小幅收縮。

### 🔭 總結 — 營運V型反轉確立、但存貨與流動性是後續追蹤點

把四頁合起來看，光寶科正處於「營運從谷底強勁反轉、獲利創高的復甦期」：長線三年營收V型反轉、毛利與淨利同步創高，ROE 重回 16.8% 優質水準；短線 Q2 營收、淨利、毛利率三者同步爆發，YoY +30% 且月營收連四個月墊高，AI 伺服器電源動能明確。財務面負債適中、現金流含金量 96% 健康，唯存貨激增 +27.8% 與流動比率跌破 150% 是擴張期的警訊，需觀察存貨去化。投資重點是追蹤「毛利率能否站穩 23% 以上」與「存貨週轉與月營收續航力」兩個領先指標，屬於電源與 AI 題材的復甦成長股。
