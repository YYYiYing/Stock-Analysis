### 📈 季月動能 — 單季爆發性反彈，毛利率跳升至30%創高

這一頁在看「最近一季、最近一個月」有沒有動起來。頎邦 2026Q2 營收 66.3 億，QoQ +15.2% 大幅上衝，從 Q1 的 57.6 億連兩季成長，淨利更從 4.37 億暴增至 9.50 億、EPS 0.59→1.28 元翻倍，毛利率同步從 23.46% 跳升至 30.30%，為近8季最高，短期動能極強。若與去年同期 53.8 億相比，YoY 約 +23.4%，擺脫連續兩季的橫盤。月營收亦連續溫升：5月21.85億→6月21.58億→7月22.88億→8月25.23億，8月 MoM +10.2% 急拉，顯示驅動IC封測需求與高階產線利用率同步回溫。整體是「量價齊揚、獲利彈升」的強動能格局，但 30% 毛利率能否續航是下一季關鍵。

### 📊 經營 — 營收小幅成長但毛利連兩年壓縮，研發強度維持高檔

這一頁在看「本業賺不賺錢」。三年營收 200.6 → 203.4 → 214.5 億，CAGR +3.4%，2025年 YoY +5.4% 溫和成長，動能不強但未衰退。毛利率卻 25.6% → 22.5% → 21.4%，兩年下滑 4.2個百分點，反映報價或產品組合壓力；營業費用率 8.9% → 9.9% → 10.2%（推銷0.86%+管理6.19%+研發3.16%）小幅墊高，費用未隨營收攤薄。研發費用 6.78 億佔營收 3.16%，投入強度穩定，符合封測業技術迭代需求。營業利益率 16.6% → 12.5% → 11.2%，連兩年壓縮 5.4 個百分點，說明獲利壓縮主因是毛利下滑而非費用失控，本業賺錢能力仍有雙位數但在收斂。

### 💰 獲利 — 獲利明顯回檔但仍穩健，股東報酬跌破高檔

這一頁在看「最後落袋多少」。稅後淨利 39.9 → 41.3 → 27.8 億，2025年 YoY -32.7%，淨利率 19.9% → 20.3% → 12.9% 大幅回落 7.4 個百分點；EPS 5.41 → 5.59 → 3.73 元，年減 33%，結束連兩年高檔。ROE 8.2% → 8.8% → 5.9%，跌破 8% 門檻、ROA 7.3% → 7.9% → 5.1% 同步回落，賺錢效率明顯轉弱但未虧損。現金股利 3.75 → 3.75 → 2.8 元，2025年配息率約 75%、殖利率僅 1.23%（因股價 227.5 元相對高檔），配息雖縮水仍維持高配息率，獲利含金量需追蹤毛利率止跌訊號。

### 🏦 財務 — 超低負債模範生，但現金與自由現金流轉弱需留意

這一頁在看「公司欠多少、現金夠不夠」。資產 542.3 億中，負債僅 68.6 億、股東權益 473.7 億，負債比率 12.7% 極度穩健（<60%），流動比率 335.4% 雖從 409% 回落仍屬優異，短期償債無虞。存貨 32.9 億，YoY +64.7% 激增且超過營收增幅（5.4%），週轉壓力升，是三頁中唯一警訊。現金部位 68.3 億較前一年 86.3 億減少 20.9%，財務彈性小幅收縮。現金流「營業 +35.5 億、投資 -35.9 億、融資 -15.5 億」——白話是「本業賺 35 億，拿去擴產投資 35 億，同時配息還債 15 億」，營業現金流為淨利的 1.28 倍、獲利含金量仍佳；但自由現金流 -15.1 億（扣除資本支出 50.5 億後轉負），為三年首見負值，反映重資本投入期，後續需觀察投資回收。

### 🔭 總結 — 獲利高檔修正、但短期動能強彈的「調整中轉強」階段

把四頁合起來看，頎邦正處於「全年獲利回檔、但單季動能已強勁轉強」的交會期：長線三年營收仍成長、但毛利與淨利連續壓縮，ROE 跌破 6%，主因是毛利率下滑而非費用暴增；短線 Q2 營收、淨利、毛利率三者同步 V 型爆發，YoY +23% 且毛利率跳回 30%，月營收亦連四個月墊高，景氣築底回升訊號明確。財務面超低負債、現金流含金量仍佳，唯存貨激增與自由現金流轉負是擴產期的正常陣痛。投資重點是追蹤「毛利率能否站穩 25% 以上」與「存貨去化速度」兩個領先指標，屬於半導體封測景氣循環的反彈觀察期。
