### 📈 季月動能 — 量價同步創高，單季營收與獲利雙雙強彈

這一頁在看「最近一季、最近一個月」有沒有動起來。聯電 2026Q2 營收 687.3 億，QoQ +12.6% 大幅成長，從 Q1 的 610.4 億連續墊高，淨利更從 161.7 億暴增至 422.6 億、EPS 1.29→3.39 元翻倍，毛利率 29.19% → 32.48% 跳升 3.3 個百分點，短期動能極強。若與去年同期 587.7 億相比，YoY 約 +17.0%，擺脫連續兩季的橫盤，並創近8季新高。月營收連四個月溫升：5月226.6億→6月229.4億→7月231.2億→8月238.4億，8月 MoM +3.1% 續強，顯示成熟製程稼動率與報價同步回溫。整體是「價漲量增、獲利爆發」的強動能格局，稼動率成為下一季關鍵領先指標。

### 📊 經營 — 營收溫和創高但毛利連三年壓縮，本業仍賺近兩成

這一頁在看「本業賺不賺錢」。三年營收 2225 → 2323 → 2376 億，CAGR +3.3%，2025年 YoY +2.2% 再創三年新高，成熟製程需求韌性十足。毛利率卻 34.9% → 32.6% → 29.0%，三年下滑 5.9 個百分點，反映價格競爭與成本壓力；營業費用率 8.8% → 10.4% → 11.3%（推銷1.02%+管理2.86%+研發7.46%）小幅墊高，其中研發 177.2 億佔營收 7.46%，投入強度為六檔最高、維持先進製程研發。營業利益率 26.0% → 22.2% → 18.5%，雖連續壓縮仍維持近兩成的高水準，說明本業獲利結構依然健康，壓縮主因是毛利下滑而非費用失控。

### 💰 獲利 — 獲利高檔回落但仍豐厚，股東報酬維持雙位數優質

這一頁在看「最後落袋多少」。稅後淨利 609.9 → 472.1 → 417.2 億，2025年 YoY -11.6%，淨利率 27.4% → 20.3% → 17.6% 連續回落；EPS 4.93 → 3.79 → 3.33 元，年減 12%，但仍為高檔。ROE 17.0% → 12.5% → 11.0%，雖從超高檔回落仍穩居 10% 以上優質水準，ROA 10.9% → 8.3% → 7.2% 亦保持高檔，賺錢效率依然出色。現金股利 3.00 → 2.85 → 2.61 元，2025年配息率約 78%、殖利率 1.68%（除息價 155 元），配息隨獲利同幅縮水但維持高配息率，獲利含金量紮實，成熟製程現金牛特性未變。

### 🏦 財務 — 低負債 + 千億現金水庫，現金流含金量極高

這一頁在看「公司欠多少、現金夠不夠」。資產 5790 億中，流動資產 2047.8 億、非流動 3742 億；負債僅 1991.4 億、股東權益 3798.6 億，負債比率 34.4% 極度穩健（<60%），流動比率 233.8% 優異，短期償債無虞。存貨 372.3 億，YoY +4.1% 溫和成長與營收增幅相當，控管穩定。現金部位 1106.6 億較前一年 1050 億增加 5.4%，重回千億水庫，財務彈性充足。現金流「營業 +998.6 億、投資 -531.5 億、融資 -392.0 億」——白話是「本業大賺 998 億，拿去擴產投資 531 億，同時還債與配息 392 億」，營業現金流為淨利的 2.39 倍、獲利含金量極高；自由現金流 521.2 億（扣除資本支出 477 億後）由前一年 53 億大幅躍升，顯示資本支出高峰後的回收期已至，現金創造能力強勁。

### 🔭 總結 — 獲利高檔正常修正、但短線重回擴張的「優質現金牛」

把四頁合起來看，聯電正處於「長線獲利從超高峰溫和回落、短線動能已強勁重回擴張」的黃金交叉：三年營收再創新高但毛利與淨利連續壓縮，ROE 仍有 11% 的優質水準；單季 Q2 營收、淨利、毛利率三者同步創高，YoY +17% 且月營收連四個月墊高，成熟製程景氣築底回升訊號明確。財務面低負債、千億現金、現金流含金量 239% 的模範生體質，自由現金流已重回 521 億高檔。投資重點是追蹤「毛利率能否止跌回升至 32%」與「月營收能否站穩 230 億」兩個景氣領先指標，屬於高配息、獲利穩定的成熟製程優質股。
