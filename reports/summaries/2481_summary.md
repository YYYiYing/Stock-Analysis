### 📈 季月動能 — 單季連續墊高，毛利率再創33%新高

這一頁在看「最近一季、最近一個月」有沒有動起來。強茂 2026Q2 營收 39.56 億，QoQ +15.6% 大幅成長，從 Q1 的 34.21 億連兩季墊高，淨利更從 2.88 億跳升至 4.88 億、EPS 0.75→1.28 元成長 70%，毛利率 32.74% → 33.22% 再創近8季新高，短期動能穩健轉強。若與去年同期 33.99 億相比，YoY 約 +16.3%，擺脫前兩季的橫盤。月營收連續溫升：5月12.97億→6月12.69億→7月13.89億→8月14.48億，8月 MoM +4.3% 續強，顯示二極體與功率元件出貨與車用需求穩健復甦。整體是「量穩價揚、獲利穩升」的健康動能格局，毛利率續航力是下一季觀察重點。

### 📊 經營 — 營收溫和成長但毛利連三年大躍升，本業獲利穩健墊高

這一頁在看「本業賺不賺錢」。三年營收 127.1 → 125.4 → 130.9 億，CAGR +1.5%，2025年 YoY +4.4% 溫和成長，動能不強但穩步墊高。亮點是毛利率 25.2% → 28.7% → 31.3%，三年大升 6.1 個百分點，每年 +3 個百分點的結構性改善，顯示產品組合往高毛利車用與功率元件轉型成功。營業費用率 18.6% → 22.1% → 22.7%（推銷5.89%+管理9.33%+研發7.45%）雖小幅墊高，但研發 9.75 億佔營收 7.45%，投入強度為六檔中高水準、支撐轉型。營業利益率 6.6% → 6.5% → 8.5%，2025年顯著提升 +2.0 個百分點，突破 8%，本業賺錢能力紮實改善，且改善由毛利驅動而非費用縮減，結構健康。

### 💰 獲利 — 獲利連三年成長且創高，股東報酬穩步墊高

這一頁在看「最後落袋多少」。稅後淨利 8.2 → 9.2 → 11.9 億，2025年 YoY +29.6% 再創三年新高，淨利率 6.5% → 7.3% → 9.1% 連續墊高；EPS 2.15 → 2.40 → 3.11 元，年增 29.6% 亦創三年新高，CAGR 約 20%。ROE 5.6% → 5.9% → 7.4%，連續改善但仍低於 8% 門檻，ROA 2.9% → 3.2% → 4.0% 同步墊高，賺錢效率穩步提升但仍有空間。現金股利 1.2 → 1.4 → 1.8 元，2025年配息率約 58%、殖利率 1.80%（除息價 100 元），配息與獲利同步成長、配息率穩健未透支，獲利含金量良好。

### 🏦 財務 — 低負債穩健、現金小幅收縮但自由現金流健康

這一頁在看「公司欠多少、現金夠不夠」。資產 295.2 億中，流動資產 157.6 億、非流動 137.6 億；負債 133.9 億、股東權益 161.3 億，負債比率 45.4% 屬穩健（<60%）且連兩年改善（49.0% → 46.0% → 45.4%），流動比率 209.6% 優異且較前一年 197.3% 回升，短期償債無虞。存貨 25.5 億，YoY -6.9% 去化且低於營收增幅，週轉壓力低、控管良好。現金部位 21.3 億較前一年 23.6 億減少 9.7%，小幅收縮但幅度可控。現金流「營業 +14.2 億、投資 -3.9 億、融資 -11.6 億」——白話是「本業賺 14 億，投資 3.9 億，同時配息還債 11 億」，營業現金流為淨利的 1.19 倍、獲利含金量健康；自由現金流 11.16 億扣除資本支出 3.0 億後仍充沛，連三年正數且穩定，現金創造能力佳。

### 🔭 總結 — 三年毛利躍升 + 獲利三連增的「轉型成長」穩健期

把四頁合起來看，強茂正處於「產品轉型成功、獲利連三年成長」的穩健成長期：長線三年營收雖僅微增，但毛利率 +6.1 個百分點的結構性躍升帶動營益率突破 8%、淨利與 EPS 三連增且創高且 CAGR 20%，ROE 亦連續墊高；短線 Q2 營收、淨利、毛利率三者同步續創高，YoY +16% 且月營收連四個月墊高，車用與功率元件需求明確。財務面低負債、高流動比、現金流含金量 119% 的健康體質，自由現金流連三年正數。投資重點是追蹤「毛利率能否站穩 32% 以上」與「月營收能否站穩 14 億」兩個轉型領先指標，屬於中小型電子元件中、獲利結構持續優化的成長型標的。
