### 📈 季月動能 — 單季營收連四季墊高，毛利率觸底回升至18%

這一頁在看「最近一季、最近一個月」有沒有動起來。南茂 2026Q2 營收 73.8 億，QoQ +6.45% 延續成長，從 Q1 的 69.4 億連四季墊高，淨利更從 5.05 億跳升至 8.92 億、EPS 0.72→1.28 元成長 77%，毛利率 13.78% → 17.96% 飆升 4.2 個百分點，短期動能轉強。若與去年同期 57.3 億相比，YoY 約 +28.7%，擺脫前兩季的橫盤並創高。月營收亦溫升：5月24.60億→6月23.84億→7月25.38億→8月28.23億，8月 MoM +11.2% 急拉，顯示封測需求與稼動率同步回溫。整體是「量穩價揚、獲利爆發」的反彈格局，但毛利率 18% 能否續航是下一季關鍵。

### 📊 經營 — 營收溫和成長但毛利崩跌，本業獲利大幅壓縮

這一頁在看「本業賺不賺錢」。三年營收 213.6 → 227.0 → 239.3 億，CAGR +5.9%，2025年 YoY +5.4% 溫和成長，封測接單量仍成長。毛利率卻 16.6% → 13.0% → 10.8%，三年崩跌 5.8 個百分點，價格競爭與成本壓力沉重；營業費用率 7.7% → 7.4% → 6.0%（推銷×%+管理+研發）雖小幅攤薄，但無法抵消毛利崩跌。營業利益率 8.9% → 5.6% → 4.8%，2025年再降至 4.8%，本業賺錢能力大幅弱化，100 元營收僅賺 4.8 元本業利益，結構惡化。

### 💰 獲利 — 獲利崩跌至谷底，股東報酬僅剩2%

這一頁在看「最後落袋多少」。稅後淨利 18.9 → 14.2 → 5.0 億，2025年 YoY -64.8% 崩跌，淨利率 8.9% → 6.3% → 2.1% 同步腰斬；EPS 2.60 → 1.95 → 0.70 元，年減 64%，連兩年大幅衰退。ROE 7.6% → 5.7% → 2.1%，已跌至 2% 的極低水準、ROA 4.1% → 3.1% → 1.1% 同步谷底，賺錢效率崩跌。現金股利 1.80 → 1.23 → 1.23 元，2025年配息率約 176%（超配透支）、殖利率僅 1.26%（除息價 97.5 元），配息已超過當年獲利、永續性堪慮。

### 🏦 財務 — 低負債穩健但存貨激增，現金與自由現金流大幅收縮

這一頁在看「公司欠多少、現金夠不夠」。資產 480.7 億中，負債 226.4 億、股東權益 254.3 億，負債比率 47.1% 屬穩健（<60%）但較前一年 44.7% 小幅墊高，流動比率 240.3% 雖從 272.6% 回落仍屬優異。存貨 33.6 億，YoY +25.0% 激增且遠超營收增幅 5.4%，週轉壓力升，是三頁中最大警訊。現金部位 148.6 億較前一年 152.2 億小幅減少 2.4%，尚穩。現金流「營業 +40.0 億、投資 -38.5 億、融資 -17.2 億」——白話是「本業賺 40 億，投資 38 億，同時配息還債 17 億」，營業現金流為淨利的 8.0 倍、獲利含金量極高（但淨利基期已極低）；自由現金流 1.5 億較前一年 8.6 億大幅收縮，現金創造能力明顯轉弱。

### 🔭 總結 — 獲利崩跌但短線觸底反彈的「谷底築底」高風險期

把四頁合起來看，南茂正處於「長線獲利崩跌、短線首見反彈」的谷底築底期：三年營收仍成長但毛利率崩跌 5.8 個百分點，淨利腰斬再腰斬、ROE 僅剩 2.1%，獲利結構惡化；但 Q2 營收、淨利、毛利率三者同步反彈，YoY+28.7% 且月營收連續墊高，封測稼動率築底訊號初現。財務面低負債仍穩，但存貨激增與自由現金流近乎枯竭是擴張期的風險。投資重點是追蹤「毛利率能否從 10% 區間真正站上 14%」與「存貨去化與月營收續航力」兩個築底領先指標，屬於半導體封測景氣中、獲利結構惡化但短線反彈的高波動標的。
